The Printer Apology is a tiny Python program that prints exactly one funny line: a printer's apology for jamming, running out of ink, and spitting out 47 blank pages at 8:59 AM, right before the big meeting. It runs with no arguments, prints the same line every time, and exits 0 — because the printer, unlike its output, is at least reliable about being sorry.

## Run it

```sh
python3 main.py
```
